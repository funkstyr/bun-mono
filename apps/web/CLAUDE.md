# apps/web

Primary product UI. **TanStack Start** SPA with TanStack Router (file-based), Vite, Tailwind v4. Talks to `apps/server` via `@bun-mono/api`'s oRPC client + TanStack Query.

## Layout

```
src/
├── router.tsx              # TanStack Router setup
├── routeTree.gen.ts        # GENERATED — do not edit (TanStack Router plugin)
├── routes/                 # File-based routes (e.g. dashboard.tsx, royalty.tsx)
├── components/             # App-level components (header, user-menu, sign-in-form…)
├── middleware/auth.ts      # Route middleware
├── lib/auth-client.ts      # better-auth client
├── utils/orpc.ts           # oRPC client wiring
└── functions/get-user.ts   # Server functions
```

## Commands

| Command                        | Purpose              |
| ------------------------------ | -------------------- |
| `bun --filter web dev`         | Vite dev server      |
| `bun --filter web build`       | Production build     |
| `bun --filter web serve`       | Preview built bundle |
| `bun --filter web check-types` | tsgo                 |

Run package builds first if you're starting cold: `bun build:packages` (handled automatically by root `bun dev`).

## Gotchas

- `src/routeTree.gen.ts` is generated by `@tanstack/router-plugin` on save/build. Never hand-edit.
- Game routes (`royalty.*.tsx`, `tic-tac-toe.tsx`, `timer.tsx`) are thin shells around `@bun-mono/royalty`, `@bun-mono/tic-tac-toe`, `@bun-mono/workout-timer` — fix bugs in those packages, not here.
- Auth client is `better-auth` via `lib/auth-client.ts`; server runs in `apps/server`.
- Env schema is `@bun-mono/env/web` — add new public vars there.

## House style

UI primitives come from `@bun-mono/core-ui` (button, card, dialog, …). Don't reach for shadcn directly; extend `core-ui` if a primitive is missing.
